# ADR-0033: First five gates production cohesion

**Status:** Implemented as the Version 29 owner-review candidate  
**Date:** 2026-08-03

## Context

Version 28 proved that all five gate families and six reef families load from
the real compressed GLB path, but phone screenshots showed a narrower problem:
the content existed while several districts still shared one blue slab value
group, multiple future canopies could read as ghost arches, reef signatures
were too small to identify reliably, and supporting merfolk could crowd or
crop at camera depth.

## Decision

- Keep the existing five encounters, six reef families, instance pools,
  shader family, camera, audio, course generation and collider planes.
- Give each gate family an authored surface palette and material-role mix while
  rebuilding the large backing mass into chipped, stepped masonry.
- Permit exactly one ceremonial canopy in the approach composition. The
  archless Astral Observatory still consumes that slot so no farther arch can
  visually bridge its twin pylons.
- Increase the signature scale and family colour separation of the existing
  six reef forms while deriving all placement from their measured bounds and
  the existing safe-lane envelope.
- Reduce guardian and supporting-cast scale at near-camera depth, vary their
  depth staging and preserve the approved role counts and choreography.

## Consequences

The pass adds no draw family, dynamic collection, texture or gameplay object.
It changes only production geometry, material response and presentation
staging behind the established runtime contracts. Owner phone review remains
authoritative for visual cohesion; automated evidence must still prove five
gate identities, six reef identities, collider alignment within 0.05 world
units, obstacle contrast, reaction windows, the 90-draw/150k-triangle/48 MB
limits and a 5,400-frame resource soak.
