# Glowfin Version 39 Native Wrapper Runbook

## Frozen wrapper identity

- Capacitor: `8.x`, exact package versions in `package-lock.json`
- Application / bundle ID: `com.karthikbs862026.glowfin`
- Native version: `0.39.0`, build `39`
- Web payload: sealed Vite `dist`
- Orientation: portrait
- Minimum platform baselines generated by Capacitor: Android API 24 and iOS 15

The wrapper owns presentation services only. Simulation, collision, replay,
score, rewards and save truth remain inside the shared deterministic web code.

## Synchronize projects

Use Node 22 or newer. Android compilation requires JDK 21 and the Android 36
SDK. iOS compilation requires macOS and Xcode.

```bash
npm ci
npm run native:sync
npm run check:native-wrapper
```

For a SHA-pinned staging candidate:

```bash
GLOWFIN_ENVIRONMENT=staging GLOWFIN_COMMIT_SHA=<40-character-sha> npm run native:sync
```

Open the native projects with `npm run native:open:android` or
`npm run native:open:ios`. Signing keys, provisioning profiles and store
credentials must stay outside the repository.

For an inspectable local debug build, sync once with
`GLOWFIN_NATIVE_DEBUG=1 npm run native:sync`. This enables only debug logging
and WebView inspection. Remove that variable and resync before producing any
candidate archive; the wrapper check requires production-safe defaults.

## Haptic contract

| Event | Native pattern |
|---|---|
| Tutorial step | Light impact |
| Near-miss / Moonflash | Light impact, throttled |
| Collision | Heavy impact, throttled |
| Cosmetic purchase | Success notification |
| Tide, objective, unlock, daily or personal-best milestone | One success notification |
| Cosmetic equip / enable-haptics confirmation | Light impact |

Haptics default on in a native wrapper and are independently switchable in
Settings. Turning them off persists locally. Web builds and unsupported native
hardware silently no-op.

## Physical acceptance

Run the install-to-tutorial-to-first-purchase/equip journey on the Samsung S22
Ultra, OPPO Reno3 Pro and two real iPhones. Confirm:

1. No HUD, tutorial or action target sits under a notch, status bar, gesture bar
   or Android navigation area.
2. Rotation never breaks portrait layout or restarts the active run.
3. Each haptic pattern is distinct but restrained, burst-throttled and stops
   immediately after Settings opt-out.
4. Background, lock, call/notification interruption and foreground resume hold
   simulation time and never duplicate input, audio or haptic events.
5. A 30-minute run stays within the existing frame, thermal and battery gates.
6. Save recovery and the tutorial completion stamp survive process termination
   without duplicate Pearls, XP, purchases or rewards.

Simulator, browser emulation and CI compilation cannot close these rows.

The owner confirmed this complete physical acceptance matrix on 2026-08-04.
Future native changes reopen the affected rows. CI additionally emits an
unsigned Android release AAB and unsigned iOS release archive; store keys,
certificates and provisioning profiles are injected only in the owner-controlled
submission environment and must never be committed.
