# Version 39 — Guided Onboarding & Store-Ready Mobile Experience

**Status:** physical-device-approved release candidate
**Baseline:** merged Version 38 at `8f529b9bd5f2e2c42e4aa27d24a88441d564b291`

## Included

- discoverable, replayable six-step guided tutorial with skip and bounded
  accessibility fallbacks;
- Capacitor 8 Android/iOS wrappers, portrait and safe-area policy, lifecycle,
  interruption, audio and optional haptic integration;
- owner-confirmed physical-device certification for the Version 39 wrapper
  matrix;
- branded Moon-Garden launcher and splash assets derived from the approved
  Glowfin acceptance target;
- explicit startup progress, local-first offline status and hosted runtime
  cache recovery;
- deterministic six-second Moonflash media with verified `Beat My Current`
  challenge links and native `glowfin://challenge/…` handoff;
- front-facing post-run celebration, unlock and recovery presentation poses;
- consent-safe coarse device/performance health events without raw device or
  GPU identifiers;
- iOS privacy manifest, age-rating/data-safety declarations and complete store
  listing copy; and
- unsigned Android release bundle and iOS release archive jobs. Store signing
  keys and provisioning profiles remain outside the repository by policy.

## Release boundary

Version 39 does not add obstacles, currencies, scenery density, advertising,
real-money purchases or competitive recovery. The web build remains the
deterministic gameplay authority; native services are presentation-only.

Cryptographic store signing and console submission are owner-controlled
release operations. The repository produces the exact unsigned candidates and
must never contain keystores, certificates, provisioning profiles or store
credentials.
